# StairGenerator (DS4)

> Independent Blender addon for generating stairs between two selected vertical faces.
>
> **Author:** This addon was written by the **DeepSeek V4 Flash** large language model.

## Features

- **Select 2 vertical faces** and generate parameterized stairs automatically
- **4 stair modes**:
  - `STRAIGHT` — single straight flight
  - `CURVED` — arc/winder flight
  - `L` — two flights with a landing and a user-set absolute turn angle
  - `U` — switchback (two parallel flights)
- **Full parameterization**:
  - Step count, width, depth (tread), height (riser)
  - Railing on/off, height, thickness, fill type (none / balusters / wall)
  - Railing style `SLOPE` (one straight handrail) or `STEPPED` (a flex point per step)
  - Classical **turned baluster** option (bulged lathe profile)
  - Landing platform options incl. L-turn angle and U slab turn
  - **Generate as Object** — build the stairs+railing into a separate `Stairs` object
    instead of fusing them into the current mesh

## Usage

1. Enter Edit Mode in Blender
2. Select exactly 2 faces that are perpendicular to the ground (vertical faces)
3. Select **StairGenerator (DS4)** tab in the Toolshelf
4. Adjust parameters as desired
5. Click **Add Stairs**

## Installation

1. Open Blender → Edit → Preferences → Add-ons
2. Click **Install** → select the `stair_builder.zip`
3. Enable the addon
